Model equations & provenance

Implements the total direct-ionization equations in Stone & Kim (2005), Eqs. 1–3. The initial hydrogen view follows Figure 1's axes and units; it is a model reconstruction, not a digitization of its curves or measurements.

t = T/B; u = U/B; S = 4πa₀² N (R/B)²
a₀ = 0.52918 Å; R = 13.6057 eV
A(t) = 1 − 1/t − ln(t)/(t+1)
BEB = S/[t+(u+1)/n] × [Q ln(t)(1−1/t²)/2 + (2−Q)A(t)]
BED = S/(t+u+1) × [D(t) ln(t) + (2−Nᵢ/N)A(t)]
D(t) = (1/N) ∫₀^((t−1)/2) [df/dw]/(1+w) dw
Nᵢ = ∫₀^∞ df/dw dw; w = W/B
df/dw = Σₚ₌₂⁶ cₚ/(1+w)ᵖ
Nᵢ = Σ cₚ/(p−1); D(t) = Σ cₚ[1−(1+(t−1)/2)⁻ᵖ]/(pN)

Cross sections are zero for T ≤ B. Coefficient integrals are evaluated analytically. Q = 1 is the paper's BEB Eq. 1; the alternate setting uses tabulated NIST Q. The n correction applies only to BEB (paper Eq. 4 / NIST introduction); this tool disables BED if any n ≠ 1 rather than silently extending BED to ionic or corrected targets. Double flags, when enabled, multiply each flagged orbital contribution by two. These are counting-cross-section estimates.

What is bundled?

Snapshot date: 19 October 2026. All orbital constants and NIST row remarks are retained in the accompanying JSON download. The snapshot is fixed, with no runtime request to NIST. Missing/empty orbital pages: CHO, CH₂O, C₂H₃O, SF₄, SF₅. Some NIST tables list only selected orbitals; “total” here means the sum of included rows. Inspect coverage before high-energy use.

H and He BED coefficients are NIST continuum polynomial fits, using the orbital B and U listed in the atomic tables. H₂ uses the Kim–Rudd fit reproduced in Fedus & Karwasz (2019), Appendix C, Eq. C4. Nᵢ is computed from each polynomial, without renormalizing it to N. The separate 0.955 rescaling mentioned on NIST's hydrogen SDCS output is not applied to the paper's raw total BED equation here. The H fit has a small negative far-tail artifact; it is retained as published and is not a general-purpose photoionization spectrum.

Custom input checks & interpretation

Require B > 0, U ≥ 0, N > 0, 0 ≤ Q ≤ 2, integer n ≥ 1, finite numbers, and at least one orbital. BED needs a complete continuum fit for every included orbital, with 0 < Nᵢ ≤ N. User polynomials are checked for negative values over the sampled physical W range; supplied fits are not automatically validated against experiment. If a continuum fit is unavailable, no BED curve or mixed BEB/BED sum is shown.

BEB agreement for targets in NIST is typically reported as 5–20% up to about 1 keV, not an uncertainty guarantee for a new target. The 1–10 keV interval is exploratory; the nonrelativistic model should not be used above 10 keV. This tool excludes autoionization (relevant to the paper's C and Al examples), resonances, neutral dissociation, and relativistic corrections.
